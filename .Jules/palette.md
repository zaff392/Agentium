## 2026-07-05 - Agentium Chat Webview Accessibility\n**Learning:** Custom form controls in the Agentium webview like select and textarea lack visual labels, making them inaccessible to screen readers. Keyboard navigation is also impaired without explicit focus states.\n**Action:** Always add descriptive `aria-label`s to form controls and explicitly style `:focus-visible` states to match existing hover states for screen reader accessibility and keyboard navigation.
