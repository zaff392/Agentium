## 2024-04-16 - Webview Keyboard Navigation and Focus Feedback
**Learning:** In VS Code webviews, native focus states aren't always sufficiently visible or styled properly because webviews isolate styles and inputs can lack clear keyboard accessibility mapping out of the box. Users relying on keyboard navigation can lose track of where they are if elements like buttons, select fields, and text areas lack `aria-label` tags and focus indication. Disabled state buttons also lack discoverability for users if it's unclear *why* the button is disabled.
**Action:** Always add `aria-label` tags to interactive elements like `button`, `textarea`, and `select` within webview HTML. Always set the `title` attribute on disabled buttons to explain the wait state (e.g., "Waiting for agent response...") so users and screen readers understand the interaction block.
