\n## 2026-06-29 - Webview Form Accessibility\n**Learning:** In VS Code webviews, custom form controls like select and textarea lack visual labels and require explicit aria-labels for screen readers. Furthermore, interactive elements often lack explicit :focus-visible styles, making keyboard navigation difficult.\n**Action:** Always add descriptive aria-labels to webview form controls and explicitly style :focus-visible states to match existing hover states for comprehensive accessibility.
